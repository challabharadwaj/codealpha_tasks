# 🎮 Hangman Game

A simple command-line Hangman game built using **Python**.

The player has to guess the hidden word one letter at a time. The player gets a limited number of wrong attempts before the game ends.

## 🚀 Features

* Random word selection
* Letter-by-letter guessing
* Maximum 6 wrong attempts
* Prevents repeated guesses
* Input validation
* Win and lose conditions
* Option to play multiple rounds
* Clean and beginner-friendly Python code

## 🛠️ Technologies Used

* Python 3
* Random module
* Sets
* Functions
* Loops
* Conditional statements
* String operations

## 🎯 How to Play

1. The game randomly selects a word.
2. The letters of the word are hidden.
3. Enter one letter at a time.
4. Correct guesses reveal the letters.
5. Wrong guesses reduce your remaining attempts.
6. Guess the complete word before running out of attempts to win.
