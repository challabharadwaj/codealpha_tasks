# 🤖 Basic AI Chatbot

A simple beginner-friendly chatbot built using Python.

## 📌 Features

* Responds to greetings
* Answers basic questions
* Uses random responses
* Runs in the terminal
* Easy to understand and modify
* No API key required

## 🛠️ Technologies Used

* Python
* Random module

## ▶️ How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run:

```bash
python chatbot.py
```

## 💬 Example

```text
================================
       BASIC AI CHATBOT
================================
Type 'bye' or 'exit' to stop.

You: hello
Bot: Hi! Nice to meet you.

You: what is your name?
Bot: I'm a Basic AI Chatbot.

You: how are you?
Bot: I'm doing great! Thanks for asking.

You: bye
Bot: Goodbye! Have a great day!
```
